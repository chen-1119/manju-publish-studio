# 漫剧发布工作台

一个从公开资源检索到贴吧发布素材整理的 Windows 本地工具，重点支持 AI 漫剧作品资源分享。

本项目独立维护，基础检索与网盘转存功能来自同作者的[漫剧雷达](https://github.com/chen-1119/manju-radar)。两个项目使用独立的本地目录、服务端口和账号配置。

## 可以做什么

- 搜索漫剧、剧集、课程教程、电子书、软件资料等内容，支持任意关键词。
- 查看首页近期热门 AI 漫剧。
- 合并多个来源的搜索结果，显示资源来源和能识别到的提取码。
- 登录自己的百度、夸克网盘后，一键转存直达分享。
- 添加七牛云或 Brave 搜索 API，扩大网页搜索范围。
- 从搜索结果制作发布素材：3 个标题备选、贴吧正文、封面图与目录图，支持编辑、复制和下载。

## 制作 AI 漫剧发布素材

“发布素材”工作台提供作品资源分享和制作教程分享两个方向。

1. 点击页面右上角“发布素材”，或资源卡片的“制作发布素材”。
2. 核对作品名，填写真实的作品介绍、集数、题材和文件目录。搜索摘要仅显示为参考，不会自动写成已确认剧情；百度实际转存完成的文件可带入目录，排队任务不能当成完成。
3. 在自己的网盘创建分享，把自己的链接和提取码填入工作台。搜索结果中的原分享链接与提取码不会自动填入发布文案。
4. 点击“生成文案与配图”，选择标题并修改正文。未填自己的链接时仍可生成草稿，不包含领取段落。
5. 可切换森林绿、深夜蓝或暖纸色，上传自己的封面或剧照；下载 1200 × 900 的封面 PNG、目录 PNG，以及 TXT 文案或 JSON 素材清单。图片下载与文案下载分别完成，JSON 不包含图片文件。

当前文案使用本地模板，图片使用本机 Canvas 排版，不需要 API 密钥，不调用 AI 模型。工作台提供文案和配图提示词，可复制到所用 AI 服务继续改写或生成概念插画。未知集数和完结状态不自动补写；“已完结”不表示资源已收集全集。

“保存本机草稿”保存一份草稿到当前浏览器，可恢复手工编辑的标题和正文；上传图片不会持久保存，恢复后需重新选择。切换资源会在本次页面打开期间保留各自的草稿；刷新后只有主动保存的草稿可以恢复。修改资料后需要重新生成，才可导出一致的素材。

工作台生成待发布素材，暂无自动创建网盘分享、自动发贴吧或拉新收益统计。实际发布位置与外链要求以目标贴吧的吧规为准；活动归因以所参与的网盘推广规则为准。

## 下载与打开

1. 前往[下载页面](https://github.com/chen-1119/manju-publish-studio/releases)，下载最新的 `manju-publish-studio-Windows.zip`。
2. 完整解压，保留文件夹内的全部文件。
3. 双击 `漫剧发布工作台.exe`，浏览器会打开工具页面。

升级时先关闭本工具的旧版，再打开新版。浏览器没有自动打开时，请使用程序窗口显示的网址。默认网址为 `http://127.0.0.1:4187`，配置与登录资料保存在 `%LOCALAPPDATA%\ManjuPublishStudio`；首次使用需单独登录网盘和设置密钥。

## 从源码运行

需要 Node.js 20 或更高版本：

```sh
npm ci
npm start
```

在浏览器打开 `http://127.0.0.1:4187/#publishing-section`。无需登录或密钥即可用本地模板生成文案和配图。

运行检查：`npm test`。Windows 打包使用 Node.js 22，运行 `npm run build:win`，结果在 `dist/漫剧发布工作台-Windows`。如需在包内集成夸克转存组件，可预先将 `quarkpan.exe` 和 `quark-login.exe` 放在 `build/quark-components/`；缺少这些可选组件时仍可构建，使用者可运行包内“安装夸克转存组件.cmd”（需要 Python 3）。

## 搜索资源

1. 输入关键词，例如 `Python 基础`、`摄影教程`、`电子书`，或具体作品名称。
2. 默认选择“不限内容”，也可以选择“漫剧作品”“教程素材”和时间范围。
3. 点击“开始搜索”，查看百度、夸克两栏结果。
4. 点击标题或“查看分享”打开资源；显示“来源网页”的结果，需要进入网页查看分享地址。
5. 想看更多内容，点击“加载更多索引结果”，或使用百度、必应、Google 的补充搜索入口。

结果较少时，可以缩短关键词、放宽时间范围，或添加下面的搜索 API。

## 一键转存

**百度网盘：** 点击“打开百度登录窗口”，在百度官方页面完成登录。电脑需要已安装 Edge 或 Chrome。

**夸克网盘：** 点击“扫码登录夸克网盘”，使用夸克 App 扫码并确认登录。

登录后，在网盘直达结果中点击“一键转存”。默认保存到自己的**网盘根目录**，会保存该分享的全部文件。若缺少提取码或转存失败，可点击“查看分享”到官方网盘页面处理。

百度若显示“任务已提交”，请等待处理并到网盘根目录核对。当前为测试版，分享链接是否有效、文件是否转存成功，请以网盘中的实际结果为准。

## 添加七牛云搜索（可选）

无需设置 API 也能搜索；设置后可增加七牛云百度搜索的网页结果。

1. 通过[作者的七牛云邀请链接](https://s.qiniu.com/RbuYve)注册或登录。
2. 按[获取密钥教程](https://developer.qiniu.com/aitokenapi/12884/how-to-get-api-key)，在七牛控制台获取自己的 **AI API Key**。
3. 打开工具页面底部“设置搜索密钥”，找到“七牛云 · 百度搜索”。
4. 粘贴密钥，点击“保存密钥”，再点击“测试连接”。
5. 测试成功后，正常输入关键词搜索即可。

七牛的双平台搜索使用 2 次 API 请求，测试连接使用 1 次。查询会消耗账户额度，邀请奖励是否能抵扣搜索费用，请在七牛控制台核对。

已有 Brave Search 密钥，也可以在同一区域保存并测试。两个服务的密钥均可独立清除。

## 换电脑使用

将下载包完整解压到另一台 Windows 电脑，即可打开工具。每台电脑需要重新登录自己的网盘，并填写自己的搜索 API 密钥；登录资料和密钥仅保存在本机。
