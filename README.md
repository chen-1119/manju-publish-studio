# 漫剧发布工作台

一个串联关键词检索、百度资源转存、自有分享和贴吧文案生成的 Windows 本地工具，重点支持 AI 漫剧作品资源分享。

本项目独立维护，基础检索与网盘转存功能来自同作者的[漫剧雷达](https://github.com/chen-1119/manju-radar)。两个项目使用独立的本地目录、服务端口和账号配置。

## 可以做什么

- 搜索漫剧、剧集、课程教程、电子书、软件资料等内容，支持任意关键词。
- 查看首页近期热门 AI 漫剧。
- 合并多个来源的搜索结果，显示资源来源和能识别到的提取码。
- 登录自己的百度、夸克网盘后，一键转存直达分享。
- 添加七牛云或 Brave 搜索 API，扩大网页搜索范围。
- 选择一条百度搜索结果，一键自动转存、创建带提取码的自己的分享链接、生成 3 个标题与简短关键词正文。
- 图片为可选项，默认不生成；按需展开配图，可使用自己的图片或生成封面、关键词图。
- 显示各步骤进度，任务记录保存在本机；刷新可恢复查看，分享失败后继续任务会复用已保存文件。

## 一键生成 AI 漫剧发布素材

1. 点击“打开百度登录窗口”，在百度官方页面登录自己的账号。
2. 输入作品名或关键词，工具自动查询公开资源索引。选择一条百度网盘直达结果，点击“一键生成：转存 → 分享 → 文案”。
3. 工具保存资源，并核对当前账号中本次保存的文件。百度排队任务只有确认完成后才进入下一步。
4. 自动为这些文件创建 **7 天有效** 的自己的分享链接，将提取码加进 `?pwd=abcd`，再生成贴吧标题、正文与少量关键词。正文不列文件名称或文件目录标题，原作者的分享链接不进入领取段落。
5. 可以补充真实的剧情、集数和更新状态，修改正文或选择标题，然后复制文案、下载图片发布到贴吧。

自动文案使用资源名称和中性关键词，不猜测剧情、集数或画质。真实文件清单只用于后台确认转存与分享范围，不带入发布文案。若触发百度验证、空间不足或分享限制，会停在对应步骤并显示原因；完成验证后继续任务。超过等待窗口的任务也可继续核对，避免重新保存。

本轮完整自动流程支持百度网盘；夸克保留搜索与独立转存功能，发布素材可手动整理。自动流程负责生成待发布文案和配图，贴吧的最终发布由你完成。

## 手动整理与编辑

“发布素材”工作台提供作品资源分享和制作教程分享两个方向。

1. 点击页面右上角“发布素材”，或资源卡片的“制作发布素材”。
2. 核对作品名，填写少量内容关键词；介绍、集数和题材可选。关键词最多 6 个，每词最多 20 字，支持空格、逗号或顿号分隔。搜索摘要仅显示为参考，不会自动写成已确认剧情。
3. 使用手动流程时，在自己的网盘创建分享并填写链接；百度一键流程会自动带入自己的链接与提取码。搜索结果中的原分享链接与提取码不会自动填入发布文案。
4. 点击“生成文案”，选择标题并修改正文。已有带 `pwd` 的链接会自动识别提取码；独立填写或修改提取码后生成，会更新链接里的 `pwd`。未填自己的链接时仍可生成草稿，不包含领取段落。
5. 没有图片也能直接复制或下载文案。需要图片时展开“配图（可选）”，可切换色系、上传自己的封面或剧照，并下载 1200 × 900 的封面 PNG 和关键词 PNG。JSON 素材清单不包含图片文件；未生成图片时 `graphics` 为 `null`。

当前文案使用本地模板，图片使用本机 Canvas 排版，不需要 API 密钥，不调用 AI 模型。工作台提供文案和配图提示词，可复制到所用 AI 服务继续改写或生成概念插画。未知集数和完结状态不自动补写；“已完结”不表示资源已收集全集。

“保存本机草稿”保存一份草稿到当前浏览器，可恢复手工编辑的标题和正文；上传图片不会持久保存，恢复后需重新选择。切换资源会在本次页面打开期间保留各自的草稿；刷新后只有主动保存的草稿可以恢复。旧版目录草稿会保留原编辑内容并标记为需要重新生成，重新生成后应用带码链接和关键词格式。修改资料后需要重新生成，才可导出一致的素材。

工作台生成待发布素材，尚未接入自动发贴吧或拉新收益统计。实际发布位置与外链要求以目标贴吧的吧规为准；活动归因以所参与的网盘推广规则为准。

## 下载与打开

1. 前往[下载页面](https://github.com/chen-1119/manju-publish-studio/releases)，下载最新的 `manju-publish-studio-Windows.zip`。
2. 完整解压，保留文件夹内的全部文件。
3. 双击 `漫剧发布工作台.exe`，浏览器会打开工具页面。

升级时先关闭本工具的旧版，再打开新版。新版重复启动会复用同一数据目录中已经运行的工具，避免多个窗口争用百度登录目录。浏览器没有自动打开时，请使用程序窗口显示的网址。默认网址为 `http://127.0.0.1:4187`，配置与登录资料保存在 `%LOCALAPPDATA%\ManjuPublishStudio`；首次使用需单独登录网盘和设置密钥。

## 从源码运行

需要 Node.js 20 或更高版本：

```sh
npm ci
npm start
```

在浏览器打开 `http://127.0.0.1:4187/#publishing-section`。无需登录或密钥即可用本地模板生成文案和配图。

运行检查：`npm test`。Windows 打包使用 Node.js 22，运行 `npm run build:win`，结果在 `dist/漫剧发布工作台-Windows`。如需在包内集成夸克转存组件，可预先将 `quarkpan.exe` 和 `quark-login.exe` 放在 `build/quark-components/`；缺少这些可选组件时仍可构建，使用者可运行包内“安装夸克转存组件.cmd”（需要 Python 3）。

## 搜索资源

1. 输入关键词，例如 `Python 基础`、`摄影教程`、`电子书`，或具体作品名称。
2. 默认选择“漫剧作品”，也可以选择“不限内容”“教程素材”和时间范围。
3. 点击“开始搜索”，查看百度、夸克两栏结果。
4. 点击标题或“查看分享”打开资源；显示“来源网页”的结果，需要进入网页查看分享地址。
5. 想看更多内容，点击“加载更多索引结果”，或使用百度、必应、Google 的补充搜索入口。

结果较少时，可以缩短关键词、放宽时间范围，或添加下面的搜索 API。

## 一键转存

**百度网盘：** 点击“打开百度登录窗口”，在百度官方页面完成登录。电脑需要已安装 Edge 或 Chrome。

如果提示登录目录被占用，先关闭本工具的旧版本及它打开的百度窗口，再重试，无需清除账号资料。如果窗口已经打开但页面加载失败，可在百度窗口刷新，或再次点击登录按钮。

**夸克网盘：** 点击“扫码登录夸克网盘”，使用夸克 App 扫码并确认登录。

登录后，百度直达结果使用“一键生成”，夸克直达结果使用“一键转存”。默认保存到自己的**网盘根目录**，会保存所选分享的全部顶层文件或文件夹。若缺少提取码或转存失败，可点击“查看分享”到官方网盘页面处理。

百度转存排队时工具会等待确认，然后自动创建自己的分享。当前为预览版，实际网盘操作仍需在登录自己的账号后验证；自动测试使用协议模拟数据，不代表真实账号已完成转存与分享。

## 添加七牛云搜索（可选）

无需设置 API 也能搜索；设置后可增加七牛云百度搜索的网页结果。

1. 通过[作者的七牛云邀请链接](https://s.qiniu.com/RbuYve)注册或登录。
2. 按[获取密钥教程](https://developer.qiniu.com/aitokenapi/12884/how-to-get-api-key)，在七牛控制台获取自己的 **AI API Key**。
3. 打开工具页面底部“设置搜索密钥”，找到“七牛云 · 百度搜索”。
4. 粘贴密钥，点击“保存密钥”，再点击“测试连接”。
5. 测试成功后，正常输入关键词搜索即可。

七牛的双平台搜索使用 2 次 API 请求，测试连接使用 1 次。查询会消耗账户额度，邀请奖励是否能抵扣搜索费用，请在七牛控制台核对。

已有 Brave Search 密钥，也可以在同一区域保存并测试。两个服务的密钥均可独立清除。

## 换电脑使用

将下载包完整解压到另一台 Windows 电脑，即可打开工具。每台电脑需要重新登录自己的网盘，并填写自己的搜索 API 密钥；登录资料和密钥仅保存在本机。
